# 硬件与安全边界

- MCU：STM32F105，FreeRTOS 静态任务。
- App Release 阶段 UART5 用于编码器：地址 1，19200 8N1，Modbus RTU 功能码 03；先读取 40001~40003 核对通讯配置，再读取 40004~40005，低 16 位在前。候选 0.2.17 的独占中位维护事务另使用功能码 06 写 2048 并回读，常规轮询仍为只读；现场写入及掉电恢复尚待验收。Debug 的 UART5 日志与编码器轮询互斥。
- Boot 阶段调试打印走 UART5：PC12/TX、PD2/RX，115200 8N1；USART1 的 115200 是 EC800 AT 通道，不是 Boot 调试口。复位前先以 115200 打开 UART5，才能看到启动首条 `[BOOT2] evt=BOOT_START`。
- CAN1：500 kbps 底盘 CANopen；CAN2：仅初始化预留。
- Flash 分区保持公共 Boot V2 边界，配置页固定 `0x0803F800`。
- 远程开关机输出已确认为 PA0（程序名 `PVIN_OUT1`，原理图网名 `EN_PWR12V_OUT1`）。高电平给外部继电器线圈供电，低电平断开；App 启动默认低电平。
- PA0 只有 MCU 输出锁存状态，没有继电器触点或整车供电反馈，平台不得将指令成功解释为整车已真实上电/下电。
- ABox 原理图确认 OUT2=PA1、OUT3=PA2、继电器=PC4、LED1~3=PB0~PB2，均高电平有效；平台提供公共板级接口，但本产品仅授权 OUT1，其他输出保持关闭。LED 当前默认关闭，无业务灯义。
- 原理图 IN1~4=PC3/PC2/PC1/PC0，IN5~8=PA7/PA6/PA5/PA4；光耦导通时 MCU 读高。公共组件对 8 路输入采样并消抖 20 ms；当前不把任一路绑定为急停、按键或接触器反馈。原理图及 SHA256 见平台 `docs/internal/board_io.md`。
- 本车没有独立的继电器或接触器状态反馈输入；不得将其作为远控门禁。本地按键用途尚未确认，不能绑定。运行反馈来自驱动器 CAN 状态与实测转速、转向状态/位置和独立编码器。
- 调试和台架必须使用硬件急停、轮胎离地和 CAN 分析仪。
