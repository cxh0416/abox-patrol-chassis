# 单圈编码器中位标定与 30 度限幅实现

日期：2026-09-09
产品：`patrol_vehicle_chassis`

## 实现边界

固件候选 `patrol-chassis-0.2.15` 保留现场 `BH38-K08-S4096-MB2` 单圈编码器。编码器一圈按 4096 count 处理，机械中位固定写为 2048；轮胎角度比例沿用 55.25 count/度，正式运行范围为 `-30000..30000 mdeg`。驱动器逐车中位仍保存为标定时的原始位置，驱动器 RAM 软限位同步收紧为 ±30°。配套平台源码版本为 `0.4.96`。

此实现建立的是源码、主机测试和固件构建证据，不是现场寄存器写入、真实轮胎角度、掉电恢复或机械限位验收结论。

## 编码器维护事务

UART5 继续由编码器任务独占。控制任务只设置维护请求，编码器任务暂停常规读取后发送 Modbus 06：从站地址 1、保持寄存器偏移 3、值 `0x0800`，并校验地址、功能码、寄存器和值的回显及 CRC。发送失败可明确判失败；已经发送但响应超时或异常时不自动重写，转入常规读取并以读回结果判断，避免不确定写入被重复执行。

写后恢复常规读取，要求连续三次新样本的高字为 0，且低字处于 2048±2 count。实时原始值必须在 0..4095；依据当前比例换算后超过 ±30° 时，不能建立正式运行坐标。运行中发生范围异常或安全配置不匹配时立即零目标、撤使能并锁存首个停止原因。

## 标定状态机

标定开始要求 OTA 空闲、普通远控及台架许可关闭、节点和反馈在线、CAN 正常、驱动无故障、行走控制器未使能、车辆电源输出已开启，并取得左右轮静止反馈。只有旧标定仍有效、两路角度一致且当前位置在旧坐标近中位 ±5° 内，才允许电机点动；完全未标定或已经跨圈时只能人工恢复到近中位。

点动只接受 `±200 mdeg` 与 `±1000 mdeg`，会话累计目标限制为起点 `±5000 mdeg`。点动复用现有安全转向执行器，行走目标固定为零；到位后立即走停止和撤使能流程。超时、失联、反馈过期、双角度偏差超限、Bus-Off 或驱动故障均结束标定、锁存故障并关闭车辆电源输出。

提交顺序为：

1. 停止转向并取得三组静止反馈。
2. 捕获转向驱动器当前原始计数。
3. 清除旧标定并完成 Flash 回读。
4. 请求编码器任务把当前位置写为 2048，并通过连续新样本读回确认。
5. 保存驱动器当前原始计数和编码器中位 2048，再次校验配置页。
6. 清除 RAM 运行坐标、撤销所有许可、关闭车辆电源输出。

旧标定清除以后任一步失败都保持未标定和输出禁用。重复提交可以从读回状态继续判断，但不会尝试把编码器回滚到旧数值。重新上电后只在 2048 安全配置、实时单圈范围及双角度一致性全部满足时允许建立运行坐标，且不会自动恢复远控接管。

## 平台配合

平台提供管理员、白名单限定的独占标定会话，按钮仅允许 `-1°`、`-0.2°`、`0.2°`、`1°`。平台对累计 `±5°` 再做一层门禁，操作审计保存操作者、VID、动作、完成阶段及设备返回的前后原始计数。提交必须二次确认；页面每 1.5 秒查询一次并续期设备可调整状态，连续约 4 秒收不到有效标定心跳时设备自行停止并下电。离开页面或网络异常仍会尽力主动请求取消。

普通远控页面只保留 20°/30°，`arm_bench_drive` 固定申请 30000 mdeg。平台要求 `get_bench_steering` 返回 `single_turn_4096_center2048_limit30_v1`、`profileReady=true` 和 `rangeValid=true`，否则明确阻止接管。

## 尚待现场验收

- 机械中位写入后编码器读回约 2048，并核对高字为 0。
- 0°、±20°、±30° 的驱动器与独立编码器反馈一致。
- 在 0°、±25°、±30° 意外断电后重新上电，坐标正确恢复但不自动接管。
- 在 ±35°/±40° 位置断电重启时拒绝接管，不得映射成反向合法角度。
- 40° 请求在页面、平台 API 和固件三层均被拒绝。

现场证据通过前不生成正式发布包，也不整体替换仓库根目录 `dist/`。
