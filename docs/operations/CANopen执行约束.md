# CANopen 执行约束

本文是内部产品实现约束，按 0.2.15 候选源码维护，不属于对外交付协议。厂商原件见 [原始资料索引](../archive/2026-08-31-input/README.md)，正式包与候选状态见仓库 [README](../../README.md)。

## 总线和节点

| 总线 | 参数 | 用途 |
| --- | --- | --- |
| CAN1 | 500 kbps、11 位标准帧 | Node 1 转向、Node 2 双驱 |
| CAN2 | 500 kbps、11 位标准帧 | 仅初始化和预留，不发送上层协议 |

Node 1 使用 SDO `0x601/0x581`、心跳 `0x701`；Node 2 使用 SDO `0x602/0x582`、心跳 `0x702`。只读模式仅允许 SDO 上传请求 `0x40`。台架转向许可仅授权 Node 1 的位置模式事务；Node 2 不得收到运行使能或非零速度命令。

## 双驱 Node 2

- DS402 速度模式：`6060=3`
- 使能序列：`6040=0x0006 -> 0x0007 -> 0x000F`
- 左右目标：`60FF`、`68FF`；左右反馈：`6069`、`6869`
- 默认使用 SDO。只有台架用 CAN 分析仪确认 RPDO2 映射确为 `0x302 = 60FF + 68FF` 后，才允许切换 PDO。
- 独立行走 RAM 许可允许 Node 2 在预运行状态通过 SDO 执行，目标限速 200 rpm。按双驱原件状态字定义核对低位 Ready/Switched/Enabled，不能复制 Node 1 对 bit 5 的掩码。使能前写入两路零速；换向确认只计入双零速写入完成之后的左右新反馈。

## 转向 Node 1

- Profile Position：`6060=1`
- 当前位置：`6064`；目标位置：`607A`
- 直行时读取 `6064` 保存为驱动器中心
- 机构轴理论换算为 `555.555556 count/机构轴°`；轮胎角度使用车型公共比例，不能把两者混用。
- 台架转向通过独立编译能力和 RAM 会话许可放行，仅 Node 1 可执行，Node 2 仍只读。
- 独立绝对编码器中心与驱动器中心必须分别保存

## 运动门禁

当前候选的独立行走目标限制为 `±200 rpm`，转向范围为 `±30°`，并受本次 RAM 许可幅度限制。独立编码器按单圈 4096 count、固定中位 2048 解释；比例为 55.25 count/轮胎度。转向驱动器使用逐车保存中位及上电建立的 RAM 坐标，比例为 2710.8 count/轮胎度。RAM 软限位按 ±30° 设置并复读，不保存驱动器 EEP。

未标定、安全配置不匹配、单圈范围异常、反馈过期、两路角度偏差大于 `2°`、节点离线、CAN Bus-Off、驱动故障或 OTA 忙时禁止运动。方向反转必须先发送左右零速，双写入完成后连续三次左右实测绝对值不超过 `20 rpm` 才可反向；每次必须为新反馈，2 秒未停车则撤销使能并锁存故障。

早期 ±300 rpm/±5° 阶段边界见 [需求与验收](../requirements/首阶段需求与验收.md)。0.2.13 正式包行走限速为 50 rpm；不能用当前候选参数描述该正式包。
