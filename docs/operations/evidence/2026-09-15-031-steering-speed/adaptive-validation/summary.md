## 速度轮廓证据

成功会话的 CAN 时间窗为 `1789451574.0` 至 `1789451675.0`。Node 1 的 CANopen `0x6081:00` 写入序列为：

`50, 200, 100, 50, 100, 200, 100, 50, 200, 100, 50, 100, 200, 100, 50, 200, 100, 50, 100, 200, 100, 50 rpm`

共 22 次写入、22 次写入 ACK、22 次读取和 22 次读回；所有读回逐项等于对应写入。向边缘运动时观察到 `200 -> 100 -> 50 rpm`，从边缘回中时观察到 `50 -> 100 -> 200 -> 100 -> 50 rpm`，正向、负向和第二次正向重复段均覆盖 200/100/50 rpm 三档。

这里验证的是转向驱动器实际收到并读回的自适应 `0x6081` 速度，以及转向角/编码器/轮速/安全状态的现场反馈；不把 MQTT 接受或构建成功单独作为动作成功证据。
