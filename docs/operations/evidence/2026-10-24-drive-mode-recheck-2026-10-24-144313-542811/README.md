# 行走驱动模式复查

日期：2026-10-24

在完成驱动模式检查后，使用 CANalyst-II 物理 CH2 对 A-BOX CAN1 的 Node 2 执行三次只读 SDO upload：

| 对象 | 结果 |
|---|---|
| `0x6061` 运行模式显示 | `3`（Profile Velocity） |
| `0x6060` 运行模式命令 | `3` |
| `0x6041` 状态字 | `0x5010` |

当前 `0x6061` 已与固件要求一致，原“模式回读不匹配”条件已解除。`0x6041` bit 3 未置位，表示当前没有驱动器 Fault 位；这不证明仍保留的软件运动故障锁存已经清除。

本次只发送 SDO upload，没有写参数、使能、运动或清故障。下一步可由操作者在确认车辆安全后执行 CAN2 `RESET_FAULT`，再读取 motion flags 确认 bit 3 消失。
