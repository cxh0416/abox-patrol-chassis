# 0.2.27 停车确认与收尾修复

本版本补齐两处停车时序：200 ms 内确认退使能后，NMT 收尾独立限定 100 ms 并优先调度；每次使能前读回 1800:01、1A00:01，确认有效的标准 TPDO1 COB-ID 和首个映射对象为 6041:00/16 bit，才允许主动状态帧确认本次停车。仅在 shutdown 应答后的等待退使能阶段接受它；未知映射、畸形或逾期帧不能产生成功。未完成 SDO 仍由原执行器消费，不会提前交给诊断事务。原有故障、反馈新鲜度和 200 ms 退使能限制保持。

主机验证：31 项 Python 测试、8 项平台 CTest、产品 C 测试通过，包含 192 ms 主动退使能、未完成 SDO 排空、未知/禁用映射、畸形/过期帧与收尾期限。ARM 构建通过，App 107088 字节。刷写及现场原始记录见 [证据索引](../evidence/2026-09-14-027-right-first/index.md)。

设备先右 5°、左 5°往返两组，再右 1°、左 1°，六次均恢复 READY，fault=0。主动退使能至 NMT 收尾延迟均低于 6 ms。结束时取消会话并关闭动力输出。平台确认固件 0.2.27、启动 CONFIRMED、OTA IDLE/ready。

本次验收范围是标定点动、停车和继续会话；未执行中位写入、完整标定或掉电保存验收。固件发布仍以 dist/release.manifest.json 和 App 哈希为准。
