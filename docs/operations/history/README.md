# 运维历史记录

本目录只保存有持续追溯价值的历史事件：正式发布、现场刷写或 OTA、台架/车辆验收、事故诊断，以及改变安全边界或操作规程的修复。正文只陈述当时的版本、证据和结论，不代表当前配置或现场状态。

当前状态统一从 [CURRENT](../../CURRENT.md) 进入；关闭的工作包也归档在本目录，不继续作为当前实施入口。

日常代码修复、主机构建、普通测试通过或候选包重建不单独建历史文档；应由提交、测试和构建产物记录。当前操作步骤、接口定义和安全约束保留在 `docs/operations/` 根目录。现场原始记录及其 SHA256 索引保留在 `../evidence/`，不得改写或删除。
