# 巡防车底盘逐车标定与参数记录

内部当前运维说明，面向 `patrol_vehicle_chassis`。正式固件以发布清单及哈希为准；现场结果查阅对应日期记录，不把源码实现当作现场验收。闲置降频后的查询唤醒和流量策略见[遥测流量与诊断策略](遥测流量与诊断策略.md)。

## 参数与持久化边界

| 项目 | 当前候选要求 | 保存位置 |
|---|---|---|
| 独立编码器 | 4096 count 单圈，机械中位固定 2048 | 编码器中位写入及 ABox 配置记录，持久性须实测 |
| 驱动器中位 | 本车机械摆正时的 Node 1 `6064` | ABox 配置页逐车保存 |
| 驱动器/编码器比例 | 2710.8 / 55.25 count/轮胎度 | 产品公共基线，不逐车复制旧采样结果 |
| 方向与容差 | 右转为正，双角度偏差 ≤2° | 产品安全配置 |
| 当前运行范围 | ±30°，受本次许可幅度约束 | 软件门禁和驱动器 RAM 软限位 |
| 上电运行中位 | 静止时依据独立角度重新建立 | RAM，断电或失效后清除 |

运行软限位写入后必须复读，**不执行控制器 EEP 保存**。历史 `Z0±27778`、±50°机构轴范围和旧编码器中心仅保留为历史记录，不直接套用于当前候选。CAN 参数及控制器配置基线变更必须按厂商资料单独确认，不能混入中位标定流程。

## 当前标定步骤

1. 核对 VID、固件版本、安全配置、驱动器与编码器型号，备份两节点当前参数；为每台车创建独立记录。
2. 保持架空与可用的本地安全停止条件，关闭普通远控及台架许可；确认 OTA 空闲、节点和反馈在线、无 Bus-Off/驱动故障、行走未使能、车辆电源输出开启，并取得左右静止反馈。
3. 开始独占 `start_center_calibration` 会话。新车、跨圈或旧标定不满足条件时，以会话起点两路原始值建立临时相对坐标，不套用旧绝对角度。
4. 使用 ±0.2°/±1° 逐步点动到现场确认的机械中位。每次点动均保留并服从驱动器当前软限位，两路相对变化差值不得超过 2°；相对会话起点另有 ±60° 兜底边界。可调整静止阶段每次查询续租 15 秒；点击点动或提交后，页面先等当前只读心跳完成，再通过保持单操作串行的平台 API 发送请求。失联、离开页面或故障时取消并核验停机。
5. 人工确认车轮机械摆正后提交 `commit_center_calibration`。设备先停机并取得三组静止反馈，捕获驱动器计数，清除旧标定并回读，然后写编码器 2048，连续三次新读数高字为 0、低字在 2048±2 后保存逐车中位并回读。
6. 轮询 `get_center_calibration` 至完成或失败，并复读配置。提交清除旧标定后失败保持未标定，输出禁用；不能凭 ACK 判定成功，也不能重放不确定的编码器写入。
7. 成功结束仍撤销所有许可、清空 RAM 运行坐标并关闭电源输出。重新上电后核验配置、单圈范围、两路角度和静止坐标，确认没有自动接管。
8. 依次完成小角度、0°/±20°/±30°、范围异常拒绝和意外掉电恢复验证，将实际结果写入本车记录。停止、换向、断链及故障门禁持续有效。

`set_calibration` 仍是内部维护接口，不能代替编码器物理中位写入事务；仅写 ABox 中位字段不证明编码器已经归零到 2048。接口定义见 [内部运维协议](巡防车底盘A-BOX内部运维协议-1.0.md)，事务细节见 [实现说明](2026-09-09-单圈编码器中位标定与30度限幅实现.md)。
