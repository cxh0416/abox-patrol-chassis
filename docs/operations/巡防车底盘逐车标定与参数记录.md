# 巡防车底盘逐车标定与参数记录

本文是 `patrol_vehicle_chassis` 的内部运维说明，用于同型号车辆的控制器基线检查、转向中位记录、软限位配置及独立编码器标定。每台车必须生成单独记录，不能复用另一台车的中位和限位数值。

## 参数分类

### 车型公共基线

以下数值来自当前硬件方案和厂家资料，可作为同批车辆的检查目标；更换电机、编码器、减速器或控制器固件后必须重新确认。

| 项目 | 基线值 | 说明 |
|---|---:|---|
| CANopen 波特率 | 500 kbit/s | 11 bit 标准帧 |
| 转向节点 | Node 1 | 心跳 `0x701`，SDO `0x601/0x581` |
| 行走节点 | Node 2 | 心跳 `0x702`，SDO `0x602/0x582` |
| 转向编码器 | 1000 线 | A/B 正交四倍频 |
| 减速比 | 50:1 | 当前转向机构 |
| 转向机构轴换算 | 555.555556 pulse/机构轴° | `1000 × 4 × 50 ÷ 360`，不能直接当作轮胎实际转角 |
| 控制器软件轴角范围 | -50°～+50° | 相对该车机械中位；对应的轮胎角度取决于连杆传动比 |
| ±50°机构轴脉冲偏移 | ±27778 pulse | 写控制器限位前必须取得该车中位 |
| CANopen 失联时间 | 0.5 s | 转向与行走均按 0.1 s 单位配置为 5 |
| 失联动作 | 急停并撤销使能 | 行走同时采用减速停机，零速减速度参数保持 1600 |

### 每台车必须重新取得

| 参数 | 取得方式 | 使用位置 |
|---|---|---|
| 设备标识 | 读取 ABox 配置 | 标定记录主键 |
| 转向机械中位 `Z0` | 车轮物理摆正后连续读取 Node 1 `6064` | 角度换算、目标位置和软限位 |
| 转向计数方向 | 在安全条件下执行小角度左右测试 | `steering_direction` |
| 转向每轮胎角度计数 | 同步记录左右轮胎实测角度和 Node 1 `6064` | `steering_counts_per_degree_milli` |
| 独立编码器中位 | 机械直行状态读取 | `absolute_center_count` |
| 独立编码器方向 | 与转向反馈同步做小角度测试 | `absolute_direction` |
| 独立编码器每度计数 | 按型号参数并用实测角度复核 | `absolute_counts_per_degree_milli` |
| 正负软限位 | 由该车 `Z0`、允许角度和机械余量计算 | Node 1 `2019/201A` |
| 双角度允许偏差 | 结合机构间隙和测量误差确认 | ABox 安全门禁，最大不得超过 2° |

## 每车执行顺序

1. 备份两个控制器当前参数，记录 CAN 节点、波特率、软件版本和参数保存状态。
2. 保持运动未使能，确认两个节点在线、故障为 0、左右实测转速为 0、CAN 无 Bus-Off。
3. 核对失联时间和失联动作。参数不一致时先修改、复读，再通过 `1010:01` 保存。
4. 现场将车轮物理摆正并保持不动，连续读取 Node 1 `6064`。把稳定值记录为该车 `Z0`，不把驱动器当前位置强制写成 0。
5. 同时读取独立编码器并记录中位。独立编码器未接入时，只能完成控制器侧中位和软限位，ABox `calibrated` 必须保持 false。
6. 根据该车的机械安全范围计算软限位。当前方案采用：`负向限位 = Z0 - 27778`，`正向限位 = Z0 + 27778`；写入 Node 1 `201A/2019` 后复读并保存。
7. 在架空或低风险条件下，先验证轮胎实际 ±5°、±10°，确认转向反馈和独立编码器的方向、角度换算及偏差，再逐步扩大到允许范围。控制器机构轴角和轮胎实际偏角必须分开记录。
8. 只有在中位、方向、量程、软限位、双角度偏差和反馈时效全部通过后，才保存 ABox 标定配置并设置 `calibrated=true`。
9. 实际中断控制发送，验证两个控制器在 0.5 s 后急停并撤销使能。
10. 受控断电重启后复读关键参数，确认控制器和 ABox 配置均持久化。

任何运动测试均必须遵守方向切换、零速三次确认、反馈时效、节点在线、故障、Bus-Off、OTA 和双转角偏差门禁。
