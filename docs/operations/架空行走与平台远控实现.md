# 架空行走与平台远控实现

内部当前实现说明，适用 `patrol_vehicle_chassis`。最新正式产物以 `dist/release.manifest.json` 和哈希为准；行走目标上限为 ±200 rpm，现场验证范围以带日期的记录为准。

## 执行与保护

独立编译能力 `PATROL_CHASSIS_BENCH_DRIVE_ENABLED` 默认关闭。打开编译能力仍需
`arm_bench_drive` 的 RAM 许可及公共控制会话。重启、停止、租约失效或故障撤销许可，
不写入 Flash 远程使能。通用运动编译开关保持关闭，未确认的硬件输入保持未配置。

Node 2 依厂商 SDO 示例进入预运行状态，经 `6060=3`、`6061` 确认、两路零速写入，
逐级执行 `6040=6/7/F` 并读取 `6041`。状态位按双驱原件第 24 页核对 Ready、Switched、
Enabled 和 Fault；不能照搬 Node 1 对 bit 5 的组合掩码。左右速度写 `60FF/68FF`，
0.2.14 的目标限制扩大到 ±200 rpm；实际转速存在控制偏差，不能把目标上限当成已测量的绝对速度上限。

换向先写左右零速，两个写入均应答后，连续三组左右新反馈均 ≤20 rpm 才发反向目标。
任何一侧旧样本不能重复计数，中间超标会清零计数。换向超时 2 秒锁存故障；停止先零速、
确认静止，再撤使能并读状态确认。SDO 应答超时 100 ms，不重放运动写入，失败关闭 PA0。
反馈、标定、双角度、节点、Bus-Off、驱动故障及 OTA 门禁持续有效。执行器读取到的
有效状态字也更新时间，但不完成诊断模块事务，不推进其轮询游标。

## 历史验证

0.2.10～0.2.13 的 10/30/50 rpm、三组换向反馈见 [行走证据](evidence/2026-09-08-bench-drive-0212.json)。不能将这些记录外推为当前 ±200 rpm 或 0.2.17 的实车验收。

## 平台

平台使用设备发出的 sessionId；接管先上电、等待运行坐标、申请许可，再建会话。
0.2.14 / 平台 0.4.93 曾用于 20°/30°/40° 逐级机械范围测试。2026-09-09 的单圈编码器候选改造将正式页面档位收紧为 20°/30°，后端、许可和固件目标上限统一为 30°。
接管保持当前转角，行走初值为零；正常释放行走输入发零速并保持会话，正常释放转向输入发 0°
自动回中。立即停车、设备拒绝、浏览器失联和平台开关关闭均结束会话，不将异常停机改为回中。
转向驱动器软限位在本供电周期按 RAM 中位设置并复读为 ±30.5°；不写入永久存储。
独立编码器须完成 0 中位置零标定并通过单圈范围门禁；这些源码限制尚不能表述为已通过机械范围或异常掉电恢复验收。
新版 v3 安全配置允许从 30°～30.5° 缓冲区重新接管，初始目标仍钳制在 ±30°；固件暂停行走并执行向内回退。旧配置不放宽接管角度。状态 `steeringBoundary` 非零时平台提示松开或减小转向，详见 [车型参数](车型参数与台架转向实现.md)。
历史记录中的开关和白名单不代表当前线上状态；使用前须现场复核管理员权限与白名单。平台停止响应仅表示请求已记录。
平台控制下发间隔 250 ms，浏览器超时仍为 750 ms，设备租约仍为 1000 ms。
临时会话采用 WAL NORMAL，减少每次续租刷盘；审计与配置连接保持原有持久化策略。
会话库独立于主库，控制调度独立于维护循环，避免日志写锁与维护耗时阻塞续租。


正式构建使用 `build_release.ps1 -BenchDrive -VerifiedCandidate <已验证候选>`，候选位于 `out/candidates/bench-drive/`；发布与清理规则见仓库 [README](../../README.md)。
