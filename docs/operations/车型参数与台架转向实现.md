# 车型参数与台架转向实现

内部当前实现说明，适用 `patrol_vehicle_chassis` 0.2.15 候选。现场验收尚未完成；0.2.13 正式包使用其自身发布清单和历史记录。

## 当前参数与坐标

独立编码器为 4096 count 单圈，机械中位固定写为 2048；比例 55.25 count/轮胎度。转向驱动器比例为 2710.8 count/轮胎度，逐车保存驱动器机械中位。右转为正，双角度偏差门限为 2°，候选运行范围为 ±30°。

上电静止并取得有效反馈后，利用独立编码器角度建立驱动器 RAM 中位；建立坐标本身不发送运动目标、不恢复控制许可。转向驱动器 RAM 软限位按 ±30° 设置并复读，不保存控制器 EEP。配置变化、反馈失效、节点重启或断电使运行坐标失效，不允许在运动中重对齐掩盖角度偏差。

配置页继续保留逐车驱动器中位、编码器中位与标定状态。旧标定即使仍能读取，也必须通过当前安全配置检查；编码器中位不是 2048 或参数不兼容时不得建立运动许可。不得把旧记录中的 3182 等中位直接写回当前候选。

## 标定与许可

标定使用独占 `start_center_calibration` 会话、受限点动、异步提交与查询；步骤见 [逐车标定](巡防车底盘逐车标定与参数记录.md)，事务细节见 [单圈编码器中位标定与30度限幅实现](2026-09-09-单圈编码器中位标定与30度限幅实现.md)。

台架转向编译能力默认关闭；候选脚本显式打开后仍需 RAM 许可和公共控制租约，默认不使能。许可幅度为 1°/3°/5°/20°/30°，不能超过本次申请幅度。纯转向许可仅接受行走零目标；独立行走许可及 ±200 rpm 保护见 [架空行走实现](架空行走与平台远控实现.md)。通用运动编译开关保持关闭。

未标定、反馈过期、双角度偏差超过 2°、节点离线、Bus-Off、驱动故障、OTA 忙、安全配置不匹配或编码器范围异常时禁止运动。停止、租约过期、故障和重启撤销许可；故障不自动恢复。未确认硬件输入不绑定，PA0 输出锁存状态不能代表接触器反馈。
