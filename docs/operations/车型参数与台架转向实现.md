# 车型参数与台架转向实现

产品为 `patrol_vehicle_chassis`。本阶段只开展架空转向测试，行走输出禁用。

## 配置与兼容

车型公共参数集中在 `vehicle_steering_profile.h`：驱动器 2710.8 count/轮胎度、独立编码器 55.25 count/轮胎度、右转为正、双角度容差 2°。这些比例来源于本车人工左右约 ±10°采样，属于调试基线，未作为轮胎绝对角度精度验收。

每车只需维护两路中位和标定有效标志。V4 布局保持 396 字节，旧比例/方向字段作为配置兼容快照保留；不匹配公共参数的有效标定禁止运动，不自动重写。新车初始不标定，本车通过运维入口写入 -85123 / 3182，固件不按 VID 或默认值自动灌入中位。清除标定不会在下次启动自动恢复。

配置保存经 Flash 回读比较后才更新 RAM。常规 OTA 和重启不清除有效中位；更换传感器或调整机械安装后重新标定。

## 台架条件

现场确认采用现有 PA0 输出及 CAN/编码器反馈，不等待新增接触器反馈和本地按键。未配置的引脚始终不绑定；`contactorFeedbackAvailable=false`，台架就绪不能解释为真实触点闭合。

`PATROL_CHASSIS_BENCH_STEERING_ENABLED` 默认 OFF。`tools/build_bench_steering.ps1` 显式开启本能力并输出到 out，通用运动开关保持 OFF；编译能力存在也不自动使能。内部 arm 创建 RAM 许可和唯一 sessionId，15 秒内必须建立控制会话；控制租约最长 1000 ms。停止、过期、故障、重启均撤销，旧会话不得在重新 arm 后复用。执行故障保持锁存，需要排查后重启再开始；不得自动恢复运动。

台架入口拒绝非零行走目标、超出当前 1°/3°/5°幅度的目标；Node 2 仅发送 SDO 读取。使能前检查 Node 2 未 Operation Enabled、左右转速不超过 20 rpm。两节点、位置/速度/状态字、编码器配置和反馈、OTA、Bus-Off 及双角度门禁持续生效。

## 执行链

CANopen 任务统一调度诊断与执行事务，最多一个 SDO 等待应答；执行期间优先读取状态、位置、左右转速和驱动故障，暂停低优先级扩展对象。执行下载不重试，避免不确定的目标触发被重放。单次应答最长 100 ms，准备最长 5 秒，停止确认最长 200 ms。

Node 1 执行 NMT Start、读取 201A/2019 软限位、设置并确认位置模式、写入并复读 6080/6081=100 rpm、把 607A 预置为进入流程时的当前位置，再逐级执行 6040=6/7/15 并读取状态字确认。运行目标由中位及车型比例反算，必须同时满足软件幅度与驱动器软限位；607A 写入后使用 1F/0F 触发。

显式停止撤销使能并确认状态后进入 NMT 预操作，不发送回中目标。通信失败、反馈失效、状态异常等故障关闭 PA0，取消待发运动事务。停止撤使能未能在 200 ms 内确认也关闭 PA0；不能以 MCU 输出回读替代真实断电验收。

## 实测记录原则

先 ±1°，通过后再 ±3°/±5°，每个会话显式停止或验证租约到期；记录目标、6064、独立编码器、左右速度、状态字及停机结果。主机仿真覆盖反馈中断与错误报文，真实断链停车另需现场断链证据，不能用仿真或 MQTT ACK 代替。

2026-09-08 0.2.5 阶段 ABox CAN1 已恢复收帧，两节点反馈新鲜；保持轮胎不动的控制器供电循环中，两路计数均保持 -83815 / 3135。不再把不同次人工回正时的计数差视为已证实的上电漂移。
