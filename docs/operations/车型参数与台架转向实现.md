# 车型参数与台架转向实现

内部当前实现说明。正式版本以 dist/release.manifest.json 为准；现场验证范围见带日期的验收记录。

## 当前参数与坐标

独立编码器为 4096 count 单圈，机械中位通过 06/0003/000F 命令置零，保存中位 0；角度按单圈最短有符号差计算，4095→0→1 连续；比例 55.25 count/轮胎度。转向驱动器比例为 2710.8 count/轮胎度，逐车保存驱动器机械中位。右转为正，双角度偏差门限为 2°，目标范围为 ±30°。

上电静止并取得有效反馈后，利用独立编码器角度建立驱动器 RAM 中位；建立坐标本身不发送运动目标、不恢复远控许可。无有效控制目标且本地门禁满足时，独立的本地回中流程可在行走确认停车后执行转向，见 [远控与本地回中](架空行走与平台远控实现.md)。转向驱动器 RAM 软限位按 ±30.5° 设置并复读，不保存控制器 EEP。配置变化、反馈失效、节点重启或断电使运行坐标失效，不允许在运动中重对齐掩盖角度偏差。

配置页继续保留逐车驱动器中位、编码器中位与标定状态。旧标定即使仍能读取，也必须通过当前安全配置检查；编码器中位不是 0 或参数不兼容时不得建立运动许可。不得把旧记录中的 3182 等中位直接写回当前候选。

## 边界缓冲与回退

安全配置为 `single_turn_4096_center0_limit30_margin05_v3`。指令范围仍为 ±30°，反馈硬保护与驱动器 RAM 软限位为 ±30.5°。任一路新鲜转角超过 ±30°、但两路均未超过 ±30.5° 时，暂停行走并保持对应侧回退状态；继续向外请求会限到该侧 29.5°，向内和回中请求仍可执行。只有两路实际角度都回到 ±29.5° 内且输入也回到该范围，才解除边界状态，避免持续满舵时反复冲边。超过 ±30.5° 仍锁存范围故障并停车。反馈过期、双角度偏差和驱动故障等门禁不变；缓冲范围不是机械安全极限的验收结论。

当前候选将转向与回中轮廓设为 300/150/75 rpm，在剩余误差 10°、3°处降档；实测角达到 ±24° 后最多 150 rpm，达到 ±27° 后强制 75 rpm。速度由固件按实测角选择，不由公共 MQTT 控制字段下发。每次改写 CANopen `0x6081` 都必须读回确认后才下发新的位置目标，`0x6080` 保持 300 rpm 上限。本轮提速尚未完成实车复验。

## 标定与执行器

标定使用独占 `start_center_calibration` 会话、受限点动、异步提交与查询；步骤见 [逐车标定](巡防车底盘逐车标定与参数记录.md)，事务细节见 [中位置零修复与验收](history/2026-09-14-028-中位置零修复与验收.md)。

转向执行器能力与运动输出开关分离。普通远控使用公共控制会话和租约，目标转角限制为 ±30°，行走目标限制为 ±500 rpm；标定使用独占会话中的受限转向点动，禁止行走。停止逻辑见[远控实现](架空行走与平台远控实现.md)。

普通接管和正式运行仍在未标定、反馈过期、双角度偏差超过 2°、节点离线、Bus-Off、驱动故障、OTA 忙、安全配置不匹配或编码器范围异常时禁止运动。唯一例外是独占中位标定会话内的受限转向点动：它不允许行走，不使用旧绝对角度，以会话起点的两路原始值建立临时相对坐标，持续校验两路相对变化并服从驱动器已有软限位。停止、租约过期、故障和重启撤销会话；故障不自动恢复。本车没有独立接触器反馈输入，PA0 输出锁存状态只代表 MCU 命令。
