# CANopen 执行约束

本文只描述产品实现约束；厂商原件保存在 `docs/archive/2026-08-31-input/`。

## 总线和节点

| 总线 | 参数 | 用途 |
| --- | --- | --- |
| CAN1 | 500 kbps、11 位标准帧 | Node 1 转向、Node 2 双驱 |
| CAN2 | 500 kbps、11 位标准帧 | 仅初始化和预留，不发送上层协议 |

Node 1 使用 SDO `0x601/0x581`、心跳 `0x701`；Node 2 使用 SDO `0x602/0x582`、心跳 `0x702`。第一阶段默认 `PATROL_CHASSIS_ACTUATION_ENABLED=0`，不得发送 NMT、SDO、PDO 或运动指令。

## 双驱 Node 2

- DS402 速度模式：`6060=3`
- 使能序列：`6040=0x0006 -> 0x0007 -> 0x000F`
- 左右目标：`60FF`、`68FF`；左右反馈：`6069`、`6869`
- 默认使用 SDO。只有台架用 CAN 分析仪确认 RPDO2 映射确为 `0x302 = 60FF + 68FF` 后，才允许切换 PDO。

## 转向 Node 1

- Profile Position：`6060=1`
- 当前位置：`6064`；目标位置：`607A`
- 直行时读取 `6064` 保存为驱动器中心
- 驱动器侧换算：`555.555556 count/°`
- 独立绝对编码器中心与驱动器中心必须分别保存

## 运动门禁

首版限制为 `±300 rpm`、`±5°`。未标定、反馈过期、两路角度偏差大于 `2°`、节点离线、CAN Bus-Off、驱动故障或 OTA 忙时禁止运动。方向反转必须先发送零速，连续三次左右实测不超过 `20 rpm` 后才可反向；2 秒未停车则撤销使能并锁存故障。
