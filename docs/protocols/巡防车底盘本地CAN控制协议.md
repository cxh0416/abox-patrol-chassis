# 巡防车底盘本地 CAN 控制协议

产品标识为 `patrol_vehicle_chassis`，协议版本为 1。所有帧均为标准数据帧，DLC 固定为 8，多字节字段采用小端序。有符号量为二进制补码。

## 指令

指令 ID 为 `0x520`。

| 字节 | 字段 | 类型及语义 |
|---|---|---|
| 0 | version | 固定为 1 |
| 1 | operation | 下表中的操作码 |
| 2–3 | sequence | uint16，请求序号 |
| 4–5 | driveRpm | int16，车辆前进为正，范围 ±1000 rpm |
| 6–7 | steeringMdeg | int16，右转为正，范围 ±30000 mdeg |

| 操作码 | 操作 | 语义 |
|---|---|---|
| 0 | QUERY | 查询状态，不上电、不接管、不续租 |
| 1 | ARM | 在零目标下申请本地控制，两个目标字段必须为 0 |
| 2 | TARGET | 更新目标并续租，要求当前本地会话有效 |
| 3 | STOP | 目标归零并撤销本地控制，必须重新 ARM 才能运动 |
| 4 | POWER_OFF | 停止控制并关闭车辆电源输出命令 |
| 5 | POWER_ON | 开启车辆电源输出命令，不授予运动许可 |
| 6 | RESET_FAULT | 在输出关闭、维护空闲等设备条件满足时复位运动故障，不自动接管 |

除 TARGET 外，目标字段必须为 0；有效 STOP/POWER_OFF 忽略目标值与旧序号，以保证停机请求生效。未知版本、帧类型或 DLC 不参与控制。

ARM 只能在无其他控制会话、标定会话空闲且设备运动条件就绪时成功。本地控制与其他控制入口互斥。每个已接受的 ARM/TARGET 给予 300 ms 租约；建议 TARGET 周期不超过 50 ms。QUERY 不延长租约。断链、门禁拒绝或控制撤销后，持续发送 TARGET 不会自动接管。

ARM 建立序号起点。后续 TARGET 的 `(新序号−上一目标序号) mod 65536` 必须在 1–32767 内，重复或旧目标不续租。序号回绕遵守相同规则。STOP/POWER_OFF 不受该顺序检查限制。

## 响应

设备对每个受支持版本的完整指令生成同一 sequence 的三帧响应。上位机只组合相同 sequence 的三帧，不把任一帧单独作为运动许可。

### ACK：`0x521`

| 字节 | 字段 |
|---|---|
| 0 | version=1 |
| 1 | result，见下表 |
| 2–3 | 原请求 sequence |
| 4 | flags，见下表 |
| 5 | stopReason，沿用底盘停止原因枚举 |
| 6–7 | feedbackAgeMs，uint16，超过可表示范围取 65535 |

result：0 接受，1 参数/操作无效，2 设备安全条件拒绝，3 控制会话占用，4 重复/旧序号，5 未接管或租约失效，6 输入已过期，7 电源输出不可用。

flags：bit 0 电源输出命令开启，bit 1 已标定，bit 2 运动条件就绪，bit 3 故障锁存，bit 4 本地控制有效，bit 5 存在控制会话，bit 6 OTA 忙，bit 7 底盘 CAN Bus-Off。输出命令不能证明继电器触点或整车供电状态。

stopReason：0 无，1 保留，2 未标定，3 反馈过期，4 双转角不一致，5 节点离线，6 CAN Bus-Off，7 驱动故障，8 OTA 忙，9 动力未就绪，10 租约到期，11 换向停车超时，12 显式停机，13 执行故障，14 编码器范围异常，15 编码器配置不符。该字段可能保留最近停止原因，当前许可同时以 flags 和反馈时效判断。

### ANGLES：`0x522`

字节 0–1 为 sequence；2–3 为 int16 驱动器转角 mdeg；4–5 为 int16 独立转角 mdeg；6 为转向节点在线标志；7 为行走节点在线标志。

### WHEELS：`0x523`

字节 0–1 为 sequence；2–3 为 int16 左轮 rpm；4–5 为 int16 右轮 rpm，均按车辆前进方向为正；6 为换向停车等待标志；7 为运动使能请求标志。

运动目标接受后仍由设备持续检查标定、反馈时效、双角度、节点、驱动故障及维护状态。方向改变由设备执行停车确认。上位机失焦、异常退出或停止控制时应发送 STOP，并在结束使用时发送 POWER_OFF；不能依赖上位机退出动作替代设备租约。无效或过期反馈不用于确认实际动作，转角在无效状态下不保证可表示。
