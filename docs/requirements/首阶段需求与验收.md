# 首阶段需求与验收

第一阶段交付安全空框架、CANopen 编解码、编码器解析、安全仲裁、电源状态机、MQTT 租约和主机测试。固件默认不发送 NMT、SDO、PDO、继电器或运动指令；平台全局远控开关默认关闭且白名单为空。

台架验收顺序：节点心跳、单轮方向、直行中心、编码器标定、`±1°..±5°` 转向、`50..300 rpm`、反向停车、断网、断 CAN、拔编码器自动停车、受控上下电。真实运动、角度和电源结果必须来自控制器反馈和台架记录。

后续范围：本地遥控、CAN2 上层协议、超过 `300 rpm/±5°` 的解锁、道路实车验收。

## 第二阶段：被动观测联调

- Release 允许向 Node 1/2 发送 SDO 上传请求 `0x40`，不得发送 NMT、SDO 下载、PDO目标或驱动使能。
- CAN1 解析 `0x701/0x702` 心跳，快速读取 `6041`、`6064`、`6069/6869`，慢速读取 `0x2000~0x2006`。
- UART5 使用 `19200 8N1`，启动读取 `40001~40003`，随后周期读取 `40004~40005`；不得写编码器配置。
- 未标定时允许上报节点在线、原始计数和诊断计数，但角度不作为有效标定角度，`safetyReady` 必须保持 `false`。
- 第二阶段通过只证明反馈链路成立，不包含真实运动、转向、电源或道路验收。
